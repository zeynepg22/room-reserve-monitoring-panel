# RoomReserve Monitoring Panel

RoomReserve Monitoring Panel is a reservation and monitoring system designed for office meeting rooms and study spaces.

## Project Purpose

The system allows users to view available rooms, create reservations, cancel bookings, and monitor room usage through dashboards.

## Main Features

- Room availability display
- Room reservation management
- Cancellation tracking
- Usage analytics
- Technical monitoring metrics
- Error logging for failed reservations

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Database: MySQL
- Monitoring: Dashboard-based metrics
